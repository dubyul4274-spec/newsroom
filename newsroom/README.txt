우리 반 뉴스룸 | 설치 및 배포

[내 컴퓨터에서 실행]
1. Node.js 20 이상 설치 (https://nodejs.org/)
2. ZIP 압축 해제 후 newsroom 폴더에서 터미널 열기
3. npm start 입력
4. 브라우저에서 http://localhost:3000 열기
5. 교사 페이지 초기 비밀번호: 1234 (외부 배포 전 반드시 변경)

[Render 배포]
1. GitHub 새 비공개 저장소 생성 후 newsroom 폴더 안 파일과 public 폴더를 업로드합니다.
2. Render에서 New > Web Service > 해당 저장소 연결
3. Runtime: Node / Build Command: npm install / Start Command: npm start
4. Environment Variables: TEACHER_PIN (새로운 강한 비밀번호), OPENAI_API_KEY (선택), OPENAI_MODEL (선택, 기본 gpt-4.1-mini)
5. 영구 저장소 사용 시 DATA_DIR을 해당 디스크 경로로 지정합니다. 영구 디스크 없는 배포는 재시작·재배포 시 데이터가 사라질 수 있습니다.
6. 배포 주소에서 교사 로그인 > 새 수업 만들기 > 수업 관리 > 학생 접속 링크 복사. 학생은 링크 또는 수업 코드로 접속합니다.

[주의]
- AI API 키가 없으면 실제 AI 기능은 작동하지 않으며 기본 점검 안내가 표시됩니다. API 사용료는 별도입니다. 키는 서버 환경변수에만 저장합니다.
- 학생 이름 대신 출석 번호 또는 별칭을 권장합니다. 기사에 이름, 연락처, 민감정보를 쓰지 않도록 지도하고 외부 AI 전송에 대한 학교 기준을 확인하세요.
- 수업 링크를 아는 사람은 승인된 신문을 볼 수 있습니다. 공개 가능한 결과물만 승인하세요. 이 버전은 별도 학생 계정 인증이 없으며 같은 브라우저에서 작성 기록을 다시 엽니다. 학교 사용 전 접근 통제와 데이터 보존 기준을 확인하세요.
- QR 코드 자동 생성, 일괄 다운로드, 댓글 및 좋아요는 이번 버전에 포함되지 않습니다. 접속 링크를 복사하여 학교에서 사용하는 QR 생성 기능으로 만들 수 있습니다.
- 인쇄/PDF는 브라우저의 인쇄 메뉴에서 PDF 저장을 선택합니다.
